# Техническое задание. QWDownloads — организатор папки загрузок

## 1. Назначение приложения
QWDownloads — десктопное приложение для Windows, которое автоматически сортирует файлы из выбранной пользователем папки загрузок по категориям, перемещает их в подпапки, находит дубликаты и очищает временные файлы.

## 2. Стек технологий
- **GUI:** PyQt6 — современный интерфейс, тёмная тема, скруглённые углы, анимации, hover-эффекты.
- **Язык:** Python 3 (Python 3.14 в целевом окружении).
- **Сборка:** PyInstaller → один .exe-файл.
- **Настройки:** `settings.json` рядом с программой.
- **Директория проекта:** `D:\program\QWDownloads\`

## 3. Функциональные требования

### FR-1. Выбор папки загрузок
- Пользователь может выбрать любую папку, не только стандартную `C:\Users\<User>\Downloads`.
- Выбранный путь сохраняется в `settings.json` рядом с программой.

### FR-2. Автоматическая сортировка
Анализ файлов в папке загрузок по расширениям и перемещение в подпапки внутри папки загрузок:

| Категория | Расширения |
|-----------|------------|
| Изображения | .jpg, .jpeg, .png, .gif, .webp, .svg, .bmp, .ico |
| Видео | .mp4, .mkv, .avi, .mov, .wmv, .flv |
| Аудио | .mp3, .wav, .ogg, .flac, .aac, .wma |
| Документы | .pdf, .doc, .docx, .xls, .xlsx, .txt, .rtf, .odt |
| Архивы | .zip, .rar, .7z, .tar, .gz, .bz2 |
| Инсталяторы | .exe, .msi |
| Прочее | остальные файлы |

### FR-3. Поиск дубликатов
- Сравнение файлов по хешу (MD5 или SHA-256).
- Пользователь может удалить дубликаты, оставив один экземпляр.

### FR-4. Очистка временных файлов
- Удаление файлов .tmp, .log, .temp, .bak старше N дней (N настраивается пользователем, по умолчанию 7 дней).

### FR-5. Современный UI
- Тёмная тема по умолчанию.
- Анимации при переключении экранов и нажатии кнопок.
- Прогресс-бар при сортировке.
- Лог действий с временными метками.

## 4. Нефункциональные требования
- Приложение собирается в один .exe (PyInstaller).
- Настройки хранятся в `settings.json` в папке с программой.
- Все операции с файлами безопасны: проверка на занятые файлы, обработка ошибок, не удаление системных/закрытых файлов.

## 5. Структура проекта
```
QWDownloads/
├── docs/
│   └── ТЗ_QWDownloads.md
├── src/
│   └── main.py          # главный файл приложения (PyQt6)
├── assets/              # иконки, ресурсы
├── settings.json        # настройки (создаётся при первом запуске)
└── QWDownloads.exe      # результат сборки PyInstaller
```

## 6. Этапы реализации
1. Составить и сохранить ТЗ в `docs\ТЗ_QWDownloads.md`.
2. Создать структуру проекта (`src/`, `assets/`, `docs/`).
3. Создать заготовку `src/main.py` с PyQt6-интерфейсом.
4. Создать `settings.json` с настройками по умолчанию.
5. Вести разработку автономно, принимая неочевидные решения по ТЗ без уточнения у пользователя.
6. Отчитаться о готовности заготовки.
